**Task Definition:**
You are tasked with engineering a Chemical Reaction Network (CRN) that functions as a **Latched Programmable Logic Gate**.
*   **Inputs:**
    *   $u_1$ (mapped to species **X**): Data Signal.
    *   $u_2$ (mapped to species **Set**): Write Enable.
    *   $u_3$ (mapped to species **Mem**): Configuration Bit.
*   **Output:** Species **OUT**.
*   **Logic:**
    1.  **Write Phase ($u_2=1$):** The system must store the state of $u_3$.
    2.  **Hold Phase ($u_2=0$):** The system must ignore $u_3$ and keep the stored value.
    3.  **Execution:**
        *   If Stored Value is High: **OUT** $\approx$ **X** (Buffer).
        *   If Stored Value is Low: **OUT** $\approx$ $1 - $ **X** (NOT Gate).

**Literature Motifs & Design Hints:**
To achieve this complex behavior with only **5 reactions**, consider the following chemical computing motifs:

1.  **Bistability (The Latch):** A memory unit usually requires **Mutual Inhibition** (e.g., Species A and B annihilate each other, or repress each other's production) or **Autocatalysis** combined with non-linear degradation. Since you cannot introduce new species, you must utilize the existing species (`Mem`, `OUT`, `X`, `Set`) to create this state.
2.  **Gated Writing:** The memory state should only change when `Set` ($u_2$) is present. Reactions changing the internal state often include `Set` as a reactant or catalyst.
3.  **Signal Inversion (The NOT Gate):** In CRNs, a NOT gate ($1 - u_1$) is typically implemented by having a constant source of Output that is annihilated or degraded by the Input ($u_1$).
4.  **Conditional Logic:** The "Programmable" aspect implies an XOR/XNOR relationship. The interaction between the Data (`X`) and the stored memory must determine the production or degradation of `OUT`.

**Constraint Reminder:**
You must select **EXACTLY 5** reactions. Do not use input parameters ($u_1, u_2, u_3$) in your reaction rates; the rates are optimized automatically, but the topology is yours to define.

=== Skeptic ===
The previous proposals by the Opportunist and Contrarian agents exhibit a fundamental flaw in their approach to the "Latching" requirement, particularly concerning the species `Mem`.

**Critique of Previous Proposals (Opportunist & Contrarian):**

1.  **Ambiguous Role of `Mem`:** Both designs interpret `Mem` as both the input species `u3` (due to the template reaction `∅ -> Mem` from `u3`) and the internal species that needs to be latched.
    *   **Control Theory & Physics Critique:** This is a critical inconsistency. A memory element, by definition, must be able to preserve its state independently of its input once written. If `Mem` is continuously produced by `u3` (via `∅ -> Mem`), then `Mem`'s concentration will always be influenced by `u3`. It cannot "preserve its state, regardless of how u3 changes subsequently" when `u2` is low, because `u3` will continue to drive its concentration. A true latch requires the memory species to be isolated from the input once the write operation is complete. The template reaction `∅ -> Mem` (from `u3`) directly contradicts this isolation.

2.  **Bistability Robustness:** While both proposed bistable motifs (autocatalysis + degradation) are theoretically sound, their effectiveness in the presence of a continuous, external input (`u3` driving `Mem`) is questionable.
    *   **Control Theory Critique:** A continuous input can shift the stable states of a bistable system or even eliminate bistability altogether, forcing the system into a monostable regime dictated by the input. For `Mem` to truly latch, its internal bistable dynamics must be significantly stronger than the `u3` input when `u2` is low, allowing it to override `u3`'s influence. This requires very specific and potentially fragile parameter tuning.

3.  **Opportunist's Autocatalysis:** The reaction `Mem + Mem -> Mem + Mem` proposed by the Opportunist for autocatalysis is not a net production reaction. From a chemical kinetics perspective, this reaction has a net change of zero for `Mem` and thus cannot contribute to the positive feedback required for bistability. A true autocatalytic reaction for bistability must result in a net increase of the species.

From a control theory perspective, this strong autocatalysis is crucial for establishing a robust "high" stable state for `Mem`, allowing it to maintain its concentration against external perturbations (like `u3` going low when `Mem` should stay high). This is a standard motif for robust bistability in chemical systems.

2.  **`Mem -> ∅`** (Degradation of `Mem`)
    *   **Purpose:** This unimolecular degradation provides the necessary decay mechanism for `Mem`. In conjunction with the autocatalysis, it helps define the "low" stable state and allows `Mem` to be written to '0'.

If `u3` is low, `Mem` is driven to a low state. If `u3` is high, the input `∅ -> Mem` (from `u3`) and the autocatalysis (R1) must compete with this degradation, allowing `Mem` to track `u3`. When `Set` is low, this reaction is inactive, allowing `Mem` to hold its state via the bistability established by R1 and R2, *overpowering* the `u3` input.

**Control Theory Justification for Latching:**
When `Set` is high, the system is in "write" mode. If `u3` is high, the combined production of `Mem` (from `u3` and R1) should overcome R3, driving `Mem` high. If `u3` is low, R3 actively degrades `Mem`, driving it low. When `Set` is low, R3 is inactive. `Mem`'s state is then primarily governed by the strong bistability from R1 and R2. For the latching to work, the internal dynamics of R1 and R2 must be sufficiently strong to make `Mem`'s concentration insensitive to changes in `u3` during this "hold" phase. This requires careful tuning of reaction rates, but the topology provides the necessary components.
