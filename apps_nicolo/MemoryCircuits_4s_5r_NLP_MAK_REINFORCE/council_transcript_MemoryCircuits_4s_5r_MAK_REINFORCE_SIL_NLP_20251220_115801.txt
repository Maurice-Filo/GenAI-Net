**Task Definition**
You are tasked with designing a **Latched Programmable Logic Gate** using a Chemical Reaction Network (CRN). The system operates with three variable inputs:
1.  **$u_1$ (Data):** The signal to be processed.
2.  **$u_2$ (Write Enable):** The control signal that opens the "write" window.
3.  **$u_3$ (Configuration):** The bit defining the logic operation (0 or 1).

The system requires two distinct behaviors integrated into one network:
*   **Latching (Memory):** The system must store the state of $u_3$ only when $u_2$ is high. When $u_2$ drops to low, the stored state must persist, ignoring subsequent changes in $u_3$.
*   **Programmable Logic:** Based on the stored memory ($M$), the output species `r` (or `OUT`) must react to the data input $u_1$:
    *   If $M=1$: Output tracks $u_1$ (Buffer).
    *   If $M=0$: Output inverts $u_1$ (NOT Gate).

**Current Best Performance (Hall of Fame)**
The current Hall of Fame contains three designs with very similar loss values, ranging from **0.203 to 0.219**.
*   **Design #0 (Best, Loss 0.203):** This design utilizes feedback loops involving `OUT` and `Set`, and degradation of `Mem`. It relies on bimolecular generation of `OUT` via `Set + X`.
*   **Design #1 (Loss 0.216):** Features strong annihilation between `Mem` and `X`, and autocatalytic-style production of `Set` and `Mem` from `OUT`.
*   **Design #2 (Loss 0.219):** Uses `X` to produce `Mem` and `Set + X` to produce `OUT`, with `OUT` acting as a regulator for `Set`.

**Critique & Observations:**
The current top designs appear to rely on ad-hoc coupling rather than distinct functional motifs. The loss values (~0.20) suggest the system is not achieving a clean "digital" logic separation or a stable latch. The designs struggle to cleanly separate the "Write" phase from the "Read/Compute" phase.

**Literature Motifs for Consideration**
To improve upon the Hall of Fame, consider standard CRN motifs for digital logic:
1.  **Bistability (Memory):** Mutual inhibition (e.g., $A + B \to \emptyset$) or autocatalysis is often required to maintain a state ($M$) after the writing signal ($u_2/Set$) is removed.
2.  **Gating:** A reaction like $A + B \to C$ acts as an AND gate. This is useful for the "Write Enable" function (only update memory if $Set$ is present).
3.  **Signal Inversion:** To implement the NOT gate behavior (when $M=0$), consider mechanisms where the presence of the data input ($X$) actively degrades or inhibits the Output, or where the Output is produced constitutively and consumed by $X$.
4.  **Conditional Logic:** The output must switch behavior based on the memory state. This implies a structure where $M$ catalyzes one reaction pathway (Buffer) and the absence of $M$ (or presence of an anti-M species) allows a different pathway (Inverter).
